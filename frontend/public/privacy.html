隐私政策

BraynLabs — CommandCraft (commandcraft.cn) / BraynLabs (braynlabs.cn)
最后更新：2026年3月30日

BraynLabs（以下简称"我们"）重视您的隐私。本政策说明我们在您使用 BraynLabs 旗下产品时如何收集、使用和保护您的信息。本政策适用于 CommandCraft 和 BraynLabs 官网。

二、信息用途

  • 账户信息：身份验证和登录。密码以 bcrypt 单向哈希存储，我们无法获知明文密码。
  • 邮箱：用于注册验证、账户安全通知。我们不会向您发送营销邮件。
  • 设备指纹：未登录时识别设备、关联聊天记录。登录后数据迁移至账户。指纹为不可逆哈希，不含可识别个人身份的信息。
  • IP 地址：注册和验证码发送频率限制、安全审计。
  • 聊天记录：提供对话上下文。我们不会将聊天内容用于模型训练。
  • 使用量统计：执行订阅套餐的使用限额。

三、统一登录（SSO）

BraynLabs 旗下产品使用统一账户系统。在一个站点登录后，通过安全的一次性票据机制同步到其他站点。
  • SSO 票据有效期仅 30 秒，一次性使用后立即失效。
  • SSO 复用已有登录会话，不会创建额外设备记录。
  • 跨站点同步通过 HTTPS 加密传输，不暴露密码或敏感数据。

四、Cookie 说明

我们仅使用一个功能性 Cookie：auth_token，用于维持登录状态。
  • 类型：HttpOnly Cookie（JavaScript 无法读取）
  • 有效期：30 天
  • 作用范围：仅在 /api 路径下发送
  • 安全属性：Secure (仅 HTTPS)、SameSite=Lax

我们不使用任何跟踪 Cookie、广告 Cookie 或第三方分析工具。

五、第三方服务

  • Resend：用于发送邮箱验证码邮件。仅传递收件邮箱和验证码内容。请参阅 Resend 隐私政策。
  • DeepSeek（CommandCraft 订阅用户）：聊天消息通过 DeepSeek API 处理。请参阅 DeepSeek 隐私政策。
  • 用户自选模型：如果您配置了自己的 API Key，消息将发送至您选择的服务商。

我们不会将您的数据出售或提供给上述服务用途以外的第三方。

六、数据存储与安全

  • 数据存储在我们的服务器上（SQLite 数据库，WAL 模式）。
  • 密码使用 bcrypt 算法加密存储。
  • 验证码使用密码学安全随机数生成，限制验证尝试次数（5次），防止暴力破解。
  • 通过 HTTPS (TLS) 加密全部传输。
  • Cookie 设置 HttpOnly、Secure、SameSite 属性。
  • 验证码发送频率受 IP 和邮箱双重限制。

七、数据保留与删除

  • 账户连续 60 天无活动将被自动删除，包括所有关联数据。
  • 过期的验证码和已使用的 SSO 票据会被定期清理。
  • 您可以在 CommandCraft 中删除单个会话及其消息。
  • 如需删除账户及全部数据，请联系我们。

八、您的权利

  • 查看账户信息和订阅状态。
  • 删除聊天记录。
  • 随时退出登录并停止使用。
  • 管理登录设备（查看并踢出其他设备）。

九、未成年人保护

本服务面向所有年龄段。我们不会有意收集 14 周岁以下未成年人的个人信息。如果您是未成年人，请在监护人指导下使用。

十、政策变更

本政策可能不时更新，更新后在本页面发布，继续使用即视为接受。

十一、联系我们

如有疑问，请通过爱发电私信或 GitHub 联系 BraynLabs。
